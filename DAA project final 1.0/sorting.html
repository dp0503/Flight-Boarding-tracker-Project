How It Works

  1. Select a field such as Name, ID, Seat, Boarding Group, Flight or Priority.
  2. Select Ascending or Descending order.
  3. For boarding queues, choose Priority Queue.
  4. Manual Quick Sort sorts the passenger dataset using a pivot and partitioning.
  5. Comparisons, swaps/moves and execution time are measured at runtime.
