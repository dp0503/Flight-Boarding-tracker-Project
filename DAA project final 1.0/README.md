# Flight Boarding Tracker

Academic frontend project for flight boarding management and DAA.

## Pages
Dashboard, Flights, Passengers, Boarding, Quick Sort, Linear Search, About Project.

## Shared Data
Flights and passengers use the same browser localStorage dataset across the working pages.

## DAA Application
**Quick Sort:** used to arrange the passenger boarding queue, especially by priority (Priority 1 to 5), and optionally by ID, name, flight, seat or boarding group.

**Linear Search:** used to find a passenger by ID, name, flight number or seat by checking records one by one.

## Removed
Flight Tracking and Algorithm Comparison pages were removed as requested.

## Run
Open `index.html` in a browser.
